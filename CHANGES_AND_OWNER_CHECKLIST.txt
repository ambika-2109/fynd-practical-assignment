FILES ADDED OR CHANGED
----------------------

1. terraform/versions.tf
   Pins the supported Terraform/provider configuration and configures the AWS provider, region, and standard tags.

2. terraform/backend.tf
   Configures an encrypted S3 remote backend with native S3 state locking. The bucket name and region are supplied by lab.sh at initialization.

3. terraform/variables.tf
   Declares AWS region, resource prefix, operator CIDR, generated WireGuard keys, Wazuh passwords, and EC2 sizes. Secret inputs are marked sensitive.

4. terraform/main.tf
   Provisions the VPC, subnet, internet gateway/routes, security groups, Ubuntu EC2 instances, encrypted disks, SSM instance role/profile, SSM SecureString secret parameters, and a restricted parameter-read policy. Creates an app/VPN VM and a separate Wazuh VM. The app VM is the only public VPN endpoint; application/Wazuh services are security-group restricted.

5. terraform/outputs.tf
   Exposes the addresses needed by the local VPN connection and verifier.

6. terraform/app-bootstrap.sh.tftpl
   Bootstraps WireGuard, Docker, ModSecurity/OWASP CRS, Juice Shop, the Wazuh agent, and Docker JSON log collection. A deterministic ModSecurity rule blocks the lab_block=1 query with HTTP 403. The Juice Shop container port is not published directly.

7. terraform/wazuh-bootstrap.sh.tftpl
   Installs Wazuh's Docker single-node deployment (manager, Indexer, and dashboard), configures credentials and a lab marker alert rule, and uses persistent Docker volumes on the encrypted Wazuh disk.

8. lab.sh
   Provides deploy, verify, and destroy commands. It bootstraps/configures the encrypted, versioned, private S3 state bucket; generates local WireGuard keys and passwords; runs Terraform; brings up the local VPN; and runs the end-to-end verifier. Destroy removes lab infrastructure but intentionally retains the state bucket.

9. scripts/verify_lab.py
   Performs bounded readiness checks, confirms an allowed application request and a deterministic blocked request, sends a fresh unique marker, and polls the authenticated Wazuh Indexer API until the event is searchable. Failures exit nonzero.

10. tests/test_verify_lab.py
    Unit tests for unique marker creation, URL construction, and locating a marker in a Wazuh event document.

11. .github/workflows/ci.yml
    CI checks Terraform format/validation, verifier unit tests, Trivy filesystem scanning, and Gitleaks. A manual deployment job depends on the checks and is intended for a protected GitHub environment and trusted self-hosted Linux VPN-capable runner.

12. README.md
    Documents prerequisites, usage, architecture, security controls, evidence, CI configuration, approximate cost, and known unverified items.

13. .gitignore
    Excludes Terraform state/plans, generated credentials, WireGuard client configuration, local state-bucket metadata, and Python cache files.
